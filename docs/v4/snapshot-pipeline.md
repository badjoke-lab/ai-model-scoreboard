# AMS v4 snapshot publishing flow

This document explains how the public v4 leaderboard is updated from the private engine snapshot.

## Repositories involved
- Scoring engine (private): `badjoke-lab/private-engine`
- Public UI (this repo): `badjoke-lab/ai-model-scoreboard`

## Files consumed by the UI
The leaderboard reads static JSON files from this repository:
- `public/data/v4/index.json`
- `public/data/v4/rankings.json`
- `public/data/v4/models.json`
- `public/data/v4/not-listed.json`

These files are generated by `private-engine`, copied here, and committed.
`index.json` is meta-based and is the source of truth for snapshot metadata.

## Manual refresh steps
1. **Generate snapshots in `private-engine`**
   ```bash
   cd ~/private-engine
   npm install        # first run only
   npm run snapshot
   ```
2. **Copy outputs into this repo**
   ```bash
   cd ~/ai-model-scoreboard
   mkdir -p public/data/v4
   cp ~/private-engine/output/index.json      public/data/v4/index.json
   cp ~/private-engine/output/rankings.json   public/data/v4/rankings.json
   cp ~/private-engine/output/models.json     public/data/v4/models.json
   cp ~/private-engine/output/not-listed.json public/data/v4/not-listed.json
   ```
3. **Commit and push**
   ```bash
   git status
   git add public/data/v4/index.json \
           public/data/v4/rankings.json \
           public/data/v4/models.json \
           public/data/v4/not-listed.json
   git commit -m "chore(v4): refresh snapshot from private-engine"
   git push origin main
   ```
4. **Validate in the UI**
   - Confirm scores, ordering, and updated timestamps on the leaderboard.
   - Confirm the methodology page renders normally.

## Snapshot validation

Every pull request that touches `public/data/v4/**` runs `scripts/validate_v4_snapshot.mjs`.
The script checks for:

- `index.json` is meta-based, with `meta.version`, `meta.updatedAt`, and numeric counts.
- `rankings.json` entries include model metadata, score components, and `updatedAt`.
- `models.json` is a map of slugs to `{ name, vendor }` objects.
- `not-listed.json` is an array (often empty).

Run it locally with:

```bash
node scripts/validate_v4_snapshot.mjs
```

Future automation should mirror these steps while keeping the public files authoritative for the site.
