# Overrides (v4)

Overrides let us supplement missing evidence, raw inputs, or links **without editing regenerated v4 artifacts** in `public/data/v4/**`.

## Location
- `overrides/v4/models/<modelKey>.json`

## Rules (must read)
- See: `overrides/v4/OVERRIDES_POLICY.md`

## Example filename
- `overrides/v4/models/meta-llama%2Fllama-3.1-8b-instruct.json`
